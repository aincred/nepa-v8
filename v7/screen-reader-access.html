About this website

The North Eastern Police Academy (NEPA) website has been designed so that people who are blind or have low vision can read it with a screen reader. Every page starts with a Skip to main content link: press the Tab key once after the page loads to reach it, then press Enter to jump straight past the header and menu to the page content.

Photographs carry a text description, headings are used in order, and tables have column headings. Where a link opens another website, it is announced as an external site that opens in a new tab. Documents such as forms, circulars and recruitment notices are provided as PDF files; a PDF reader is needed to open them.

Keyboard and display options

The whole website can be used without a mouse. Use Tab and Shift + Tab to move between links and buttons, and Enter to open a link or menu.

The accessibility button at the top right of every page lets you increase (A+), reset (A) or decrease (A-) the text size and switch to high contrast. The language buttons let you read the site in Hindi or English.

Screen readers

This website can be read with the following screen readers. Information about each one is on the supplier's own website.

  • NVDA (NonVisual Desktop Access) (external site, opens in new tab) – free, for Windows
  • JAWS (Job Access With Speech) (external site, opens in new tab) – commercial, for Windows
  • Orca (external site, opens in new tab) – free, for Linux
  • VoiceOver (external site, opens in new tab) – built into Apple devices
  • TalkBack (external site, opens in new tab) – built into Android devices

Need help?

If any part of this website cannot be read with your screen reader, please tell us the page and the problem so that we can fix it. See also our Accessibility Statement.
